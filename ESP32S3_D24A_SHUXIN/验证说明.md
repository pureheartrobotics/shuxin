# 验证结果

2026-09-23：工程已改为 ESP32-S3 N16R8 与 D24A 四路电机驱动，使用本机 ESP-IDF 5.5.4、Xtensa GCC 14.2.0 完整编译并链接成功。目标为 esp32s3，Flash 16MB，Octal PSRAM 8MB 配置已启用；应用固件大小约 236KB。

Windows 主机模拟测试通过，并以 Wall/Wextra/Werror 编译。测试覆盖四个电机的前进、后退、原地左右转真值，四个 LEDC PWM 通道，重复命令续期，4秒失联停机，50ms刹车，刹车中恢复运动，命令范围和格式校验。

模拟与编译测试不能代替实物验证。尚未实际烧录，也未测量电平转换、PWM波形、电机方向、堵转电流或负载温升。首次必须架空低速测试。
