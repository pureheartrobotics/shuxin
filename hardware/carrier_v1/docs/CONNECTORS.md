# 载板连接器定义（Carrier V1.4 · JST XH 2.50）

冻结目标：线束全部 **JST XH（针距 2.50 mm）**；模组座仍用 2.54 排针（K11C 30Pin、S3 DevKit）。

> **不要买「XH2.54」**：那是杂牌脚距。本板封装为 KiCad `Connector_JST` 的 `P2.50mm`。

电源域：K11C **3.3 V**；电机 VM ≈ 电池；舵机 **8.4 V**；GND 星接 / 整板铺铜。

---

## 仍用排针

| 位号 | 型号 | 用途 |
|------|------|------|
| P1 | 2×15 2.54 母座 | K11C 30Pin；**Pin25/27 DEBUG 不布线** |
| P2 / P3 | 1×22 2.54 母座 | ESP32-S3-DevKitC-1；**排距 22.86 mm** |
| JP1 | 2.54 跳线帽 | `+5V_LOGIC` → `S3_5V`；**烧录时拔掉** |

### P2 / P3 关键脚（S3）

| 座-针 | 网名 | 备注 |
|-------|------|------|
| P2-1,2 | +3V3 | |
| P2-20 | DIN2 | **GPIO14**（非 USB D+） |
| P2-21 | S3_5V | 仅经 JP1 |
| P2-22 | GND | |
| P3-1,21,22 | GND | |
| P3-18 | DIN1 | GPIO21 |
| P3-19 | NC | 勿接 DIN2 |

## 线束：JST XH 2.50

### J_UART — XH 4P（针4 NC，防与舵机 3P 互插）

| 针 | 网名 |
|----|------|
| 1 | UART_K11C_TX |
| 2 | UART_K11C_RX |
| 3 | GND |
| 4 | NC |

与 P1-15/17 同网并联：只焊排针 **或** 只插 XH，避免双驱。

### J_TOF — XH 4P

| 针 | 网名 |
|----|------|
| 1 | +3V3 |
| 2 | GND |
| 3 | I2C3_SCL |
| 4 | I2C3_SDA |

### J_CTRL_AB — XH 8P 直插

| 针 | 网名 |
|----|------|
| 1–7 | STBY_J … BIN2_J（经 100R） |
| 8 | GND |

### J_CTRL_CD — XH 8P **卧式**（防与 AB 互插）

| 针 | 网名 |
|----|------|
| 1–6 | PWMC_J … DIN2_J |
| 7 | +5V_LOGIC |
| 8 | GND |

### J_ENC_A/B/C/D — XH 4P

| 针 | 网名 |
|----|------|
| 1 | ENC_x_A |
| 2 | ENC_x_B |
| 3 | +3V3 |
| 4 | GND |

### J_SERVO_PAN / TILT — XH 3P

| 针 | 网名 |
|----|------|
| 1 | SERVO_* |
| 2 | V_SERVO |
| 3 | GND |

壳体丝印：功能名；锁扣朝板外。
