# 打板说明 Carrier V1.5

## 建议参数

| 项 | 值 |
|----|-----|
| 层数 | 2 |
| 尺寸 | **170 × 120 mm**（相对 V1.3 的 160×110 变大，装机前量壳体） |
| 板厚 | 1.6 mm |
| 铜厚 | 1 oz |
| 阻焊 | 绿油白字 |
| 表面 | HASL |
| 信号线宽/间距 | 0.2 / 0.2 mm |
| 电源线宽 | VBAT/VM/V_SERVO **1.6 mm** + 分区铺铜 |
| 逻辑电源 | +3V3 / +5V_LOGIC / S3_5V **0.5 mm** |
| 过孔 | **0.6 / 0.3 mm**（与 FreeRouting 一致） |
| 安装孔 | M3 **NPTH** 3.2 mm |
| 版本 | Title **Carrier V1.5** / Revision **F** |
