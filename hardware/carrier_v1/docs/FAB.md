# 打板说明 Carrier V1

## 建议参数（首板）

| 项 | 值 |
|----|----|
| 层数 | 2 |
| 尺寸 | **140 × 100 mm**（V1.1） |
| 板厚 | 1.6 mm |
| 铜厚 | 1 oz（电源区可加粗 / 开窗） |
| 阻焊 | 绿油白字即可 |
| 表面 | HASL 有铅或无铅 |
| 最小线宽/间距 | 0.2 / 0.2 mm 足够（信号）；VM / V_SERVO ≥ 1.5 mm 或铺铜 |
| 过孔 | ≥ 0.3 / 0.6 mm |

## 布局要点

1. **大电流**：JBAT → F1 → SW1 → VM 铺铜；分支到 K11C、D24A、Buck  
2. **舵机 8.4 V** 与逻辑分区，靠近 P6 放电解电容  
3. **UART / I2C** 远离电机 PWM 回流；差分不是必须，短而靠边走  
4. **编码器** 线尽量等长、旁路电容靠近座子  
5. **星地**：信号地与功率地在 D24A 附近单点汇合  
6. DevKit USB 口朝外，便于烧录；JP1 丝印写清「烧录拔掉」  

## 装配顺序建议

1. 电源路径与 Buck，空载测 VM / 8.4 V  
2. 插 S3 + 接 D24A 控制/编码（JP1 视情况）  
3. K11C UART loopback / `ENC` 回报  
4. 舵机与 ToF  

## 验收

- [ ] 无电池时 USB 烧录 S3 正常（JP1 开路）  
- [ ] `F/B/L/R/S` 四轮方向与字母表一致  
- [ ] `ENC` 四轮计数；前进时左正右按固件 invert  
- [ ] `HEAD/NOD/SHAKE` 舵机只吃 8.4 V 轨  
- [ ] ToF 在 K11C `i2cdetect` 见地址
