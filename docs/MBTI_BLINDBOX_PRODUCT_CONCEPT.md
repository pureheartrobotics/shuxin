# 陪伴机器人「MBTI 人格盲盒」产品方案（对外评审版）

> **文档用途**：描述产品想法与体验设计，供 GPT 或外部顾问评估，**不含实现细节与内部架构**。  
> **版本**：v1.0 · 2026-06  
> **产品**：初心 — 语音陪伴型硬件机器人

---

## 一、背景

### 我们在做什么

初心是一款**语音陪伴机器人**：用户通过小程序绑定设备后，可与机器人自然对话。机器人有稳定的核心人格（价值观、边界、名字），并能在长期互动中记住与用户的相处内容。

### 为什么需要「盲盒」

硬件产品若每台完全一样，缺少**开箱惊喜**和**收藏/对比**话题。我们希望：

- 每台机器人在出厂时已「自带一种性格气质」，但用户**第一次连接之前不知道**；
- 首次绑定或首次开机时，用仪式感呈现「你抽到了哪一种 MBTI 伙伴」；
- 同一用户若购买多台，可能抽到不同性格，形成「集齐 16 型」的轻量玩法。

### MBTI 在这里指什么

采用业界通用的 **16 型 MBTI**（如 INFJ、ENFP、ISTJ 等）作为**性格标签**，不是心理测评工具，而是：

- 用户可理解的「这台机器人是谁」；
- 内容团队可围绕 16 型撰写差异化语气；
- 对话中体现为：用词、节奏、关心方式、幽默程度等**可感知差异**。

**重要边界**：MBTI 是「初始气质」，开箱后**固定**；不是随聊天不断变型的心理测试，也不是用户可随时重抽的抽卡游戏。

## 二、核心产品概念

### 2.1 一句话

> **每台机器人出厂时随机一种 MBTI 气质；用户首次连接时「开箱」揭晓，之后终身锁定（售后可重置）。**

### 2.2 与用户的关系

| 维度 | 设计 |
|------|------|
| 一台机器人 | 一种 MBTI，开箱后不变 |
| 一个用户多台机器人 | 每台可不同 MBTI，像养了多个性格不同的伙伴 |
| 声音 / 音色 | 由用户账号侧统一配置（同一用户多台机器**声音可相同**） |
| 说话气质 | 由**每台机器自己的 MBTI** 决定（同声音、不同性格） |
| 记忆 | **每台机器人单独记住**与主人的相处；多台之间不混用 |

### 2.3 盲盒三态（用户视角）

```text
未开箱 → 已揭晓（仪式中）→ 已锁定
```

| 状态 | 用户感受 |
|------|----------|
| **未开箱** | 绑定前/首次连接前：不知道这台是什么性格 |
| **已揭晓** | 正在看动画、听播报：「你的伙伴是 INFJ · 提倡者」 |
| **已锁定** | 之后每次使用直接显示该类型，不再随机 |

## 三、体验流程（怎么「搞」盲盒）

### 3.1 出厂（用户不可见）

- 工厂批量生产时，为每台设备**预先分配**一种 MBTI（随机、均匀即可）。
- 分配结果写入设备档案，**不对用户展示**，直到首次开箱。
- 目的：保证质检可测、售后可追溯，同时保留用户侧惊喜。

### 3.2 首次绑定（小程序）

1. 用户扫码绑定机器人；
2. 若该设备**从未开箱**：
   - 展示短动画（盲盒/光效/卡片翻转等）；
   - Reveal：**MBTI 四字码 + 中文昵称 + 一句 tagline**（例：「INFJ · 提倡者 — 安静而神秘，记得你说过的小事」）；
   - 引导「和 TA 说第一句话」。
3. 若该设备**已开箱且已绑定过**（重复绑定同一账号）：
   - 不再随机，直接展示**已有 MBTI**，提示「设备已绑定 / 你的伙伴仍是 xxx」。

### 3.3 首次开机对话（机器人侧）

与小程序**同一结果**，避免两端不一致：

1. 设备首次连上云端并完成鉴权；
2. 机器人用 TTS 播报开箱台词（可复用 tagline 或稍长欢迎语）；
3. 可选：灯光 / 屏幕展示 MBTI 缩写或图标；
4. 之后正常进入倾听与对话，**气质已生效**，无需用户再设置。

### 3.4 日常使用

- 对话语气随 MBTI 略有差异（同账号下 INFJ 与 ENTP 两台机器应对同一问题风格不同）；
- 小程序「我的设备」可查看每台机器的 MBTI 卡片；
- **不提供**用户自助「再抽一次」。

### 3.5 售后（内部）

- 客服/运营可在后台查看：设备 MBTI、是否已开箱；
- **重置盲盒**：仅售后场景，重新随机并回到「未开箱」（是否清空该机器上的相处记忆，需二次确认，默认清空）。

## 四、内容需求（需要「写」什么）

盲盒要成立，**16 型每一型都要有一套可运营文案**，建议每型至少包含：

| 字段 | 用途 | 示例 |
|------|------|------|
| 类型码 | 展示 | INFJ |
| 中文名 | 展示 | 提倡者 |
| Tagline | 开箱卡片 + 短播报 | 「安静而神秘，记得你说过的小事」 |
| 气质说明 | 小程序详情页，2–3 句 | 偏内向、重共情、少废话… |
| 对话风格指引 | 给 AI 的「怎么说」 | 200–400 字：称呼习惯、句式、禁忌 |
| 可选示例句 | 内部试听 / 品控 | 3 条代表台词 |

**写作原则（建议）**：

- 所有类型共享同一核心人格（不 OOC，不讨好到失真）；
- 差异体现在**表达方式**，而非价值观对立；
- 避免刻板印象式嘲讽（如「T 型一定冷血」）；
- Tagline 宜口语化、有记忆点，适合 TTS 朗读。

**交付形态**：16 份独立文档或表格即可，**不要求**在本文中约定技术格式。

## 五、产品规则摘要

### 5.1 必须遵守

- 16 型标准池，出厂随机，**开箱后锁定**；
- 首次连接必须有一次**双端一致**的开箱呈现（小程序 + 机器人）；
- 一台机器人一份相处记忆；多机不串记忆；
- 设备转赠给他人：新主人**不应**看到上一任的对话内容；
- 原主人若再次绑定同一台机器：应能找回**与这台机器之前**的相处（而非与其他机器混淆）。

### 5.2 明确不做（本期）

- 用户付费/看广告重抽 MBTI；
- 自定义非 MBTI 性格池；
- 开箱后 MBTI 随时间自动变化（长期「成长」另立项目）；
- 把 MBTI 包装成专业心理测评结果。

## 六、成功标准（产品验收）

| 编号 | 标准 |
|------|------|
| P-1 | 首次绑定能完成开箱仪式，用户能说出自己的机器是哪种 MBTI |
| P-2 | 第二次绑定同一台、同一账号，不再随机，展示原类型 |
| P-3 | 同账号两台机器 MBTI 可不同，且对话气质可区分 |
| P-4 | 同账号两台机器「谁记得什么」不混淆 |
| P-5 | 转赠后新用户看不到旧用户的私密对话 |
| P-6 | 16 型文案齐备前，可先试点 3–5 型，其余用通用气质兜底 |

---

## 七、风险与开放问题（供外部评估）

1. **开箱后锁定**：用户若不喜欢抽到的类型，会否产生差评？是否仅依赖售后重置？
2. **同声音、不同性格**：用户能否感知差异？是否需要开箱后一句「试听差异」Demo？
3. **MBTI 标签**：年轻用户熟悉，部分用户可能误解为心理测试，文案是否要免责声明？
4. **收集玩法**：是否要显性做「图鉴 / 16 型收集」，还是只做隐性差异？
5. **与「长期成长」关系**：MBTI 是种子，未来若加入「越聊越像你」的成长，如何避免人格漂移过大？
6. **二手设备**：转赠场景下，开箱状态是否继承（已开箱则新主人直接看到类型，不再仪式）？

---

## 八、建议实施顺序（产品视角）

| 阶段 | 目标 |
|------|------|
| **M1** | 定稿 16 型写作规范 + 先写 3 型试点文案 |
| **M2** | 小程序开箱页 + 设备首次欢迎播报（可 mock 数据联调） |
| **M3** | 16 型文案齐套 + 对话气质可感知验收 |
| **M4** | 多机记忆隔离 + 转赠/再绑规则验收 |
| **M5** | 售后重置流程 + 图鉴/运营活动（可选） |
