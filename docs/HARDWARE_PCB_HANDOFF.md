# 硬件 / PCB 交接说明（K11C + S3 + D24A）

给画板朋友看的冻结快照说明。仓库路径见文末 GitHub 链接（以 push 后为准）。

## 1. 产品分层（不要画成一颗全能主控）

| 层 | 现用硬件 | 职责 |
|----|----------|------|
| 大脑 | KickPi **K11C**（RK3566 Android） | 屏、语音、Wi‑Fi、`/ws/voice`、UART 下发口令 |
| 肢体 MCU | **ESP32-S3** DevKit + 固件 `ESP32S3_D24A_SHUXIN/` | 电机 PWM/方向、舵机、四轮编码器闭环 |
| 电机驱 | **D24A**（TB6612 四路 + 编码座） | VM 电池直供；逻辑 5V/3.3V |
| 头 | 2× HV 舵机 | **独立 8.4V 降压**，与 12V 电机域只共地 |
| 测距 | VL53L5CX | **已迁到 K11C I2C**（S3 不再接 ToF） |

量产优先：**载板固定互连**（零杜邦），MCU/驱动可先继续贴模组。

## 2. 电源

```text
锂电池 ~10.8–12.6V
 ├─ K11C DC（约 12V）
 ├─ D24A VIN / 电机 VM
 ├─ Buck → 8.4V → 两舵机 V+（分线器可留）
 └─ 全车 GND 星接（建议以 D24A 为参考）
```

- 勿从 K11C 小电流口给电机  
- 烧录 S3 时：拔掉 D24A→S3 的 5V，只用 USB  

## 3. 轮位与电机字母（实车）

| 电机字母 | 位置 | 闭环侧 |
|----------|------|--------|
| C | 左前 | 左 |
| B | 右前 | 右 |
| D | 左后 | 左 |
| A | 右后 | 右 |

右侧 A/B 固件默认 `MOTOR_INVERT`；左侧 C/D 不反相。

## 4. S3 关键脚位（冻结）

### 4.1 与 K11C
- K11C UART7 **Pin17 TX → S3 GPIO18**
- K11C UART7 **Pin15 RX ← S3 GPIO17**
- GND 共地；3.3V TTL  

### 4.2 D24A 控制（见 `ESP32S3_D24A_SHUXIN/README_接线与使用.md`）
PWM / IN1/IN2 / STBY 按现表；项目内另有 D24A 原理图 PDF：`3.D24A四路驱动稳压模块/`。

### 4.3 舵机
- 水平 GPIO1、俯仰 GPIO2（PWM 50Hz）  
- 电源 8.4V 独立，信号共地  

### 4.4 四轮正交编码器（勿踩雷区）

**禁止**：GPIO48（板载 RGB）、GPIO19/20（USB D±）、GPIO33–37（Octal PSRAM）

| 电机 | 信号 | GPIO |
|------|------|------|
| A 右后 | E1A / E1B | 46 / 3 |
| B 右前 | E2A / E2B | 38 / 13 |
| C 左前 | E3A / E3B | 47 / 41 |
| D 左后 | E4A / E4B | 42 / 39 |

编码 3.3V 走电机 6P 座；动力线勿插错编码针。

### 4.5 串口协议（S3）
`F/B/L/R/S`、`HEAD`/`NOD`/`SHAKE`、`ENC` / `ENC R`（回报四轮 count/cps 与 trim）

## 5. 建议载板内容（下一版）

1. K11C 扩展座 / 排线（UART7 + I2C ToF + 3.3V/GND）  
2. S3 模组座或直接贴 WROOM  
3. D24A 兼容连接器或把 TB6612+编码座画进板  
4. 8.4V Buck（≥5A）+ 舵机端子  
5. 电池 XT30/XT60、总开关、保险、星地  
6. 测试点：UART、E1–E4、3.3V、VM、舵机 8.4V  
7. 烧录口：S3 USB 与/或 UART0 隔离

## 7. 已知坑（画板时避开）

- DevKitC-1 **GPIO48 = RGB LED**，不能接编码  
- S3 **原生 USB** 与 CH340 UART 口不同；量产控制走 UART1↔K11C  
- 编码座虚插会导致单轮 `ENC` 为 0（已用 C/D 对插验证过板子本身）
