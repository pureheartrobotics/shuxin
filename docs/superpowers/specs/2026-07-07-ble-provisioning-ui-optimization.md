## 1. 优化背景

经过前期多轮的联调与修复，微信小程序的蓝牙配网功能已经在功能与协议层彻底调通：
* 解决了 Android 的 `createBLEConnection` 超时和连接冲突问题。
* 解决了 iOS 的 `nocharacteristic` 和 `notify` 的 `internal error` 问题。
* 解决了 proto3 默认值 0 省略导致的 `status=-1` 解析报错。
* 支持了广播无名字但有配网服务 UUID 的设备扫描与连接。

现在，当前页面的视觉和交互设计需要进行一次全面提升，使之符合大众审美并展现出高级质感，同时与“初心”陪伴型 AI 智能体温和、自然、宁静的调性（Warm Companion Theme）保持一致。

## 2. 视觉设计系统 (Warm Companion Theme)

延续并精细化“初心”品牌色系，使用以下色彩与样式规范：

|---|---|---|
| **主背景色** | `#fffaf3` (温暖乳白底色) | 柔和、舒适、家居陪伴感，减少科技冰冷感 |

| **边框线条** | `rgba(128, 94, 69, 0.12)` (淡棕灰) | 细腻的线框感 |

## 3. 页面交互流程与视觉设计细则

### 3.1 步骤一：未扫描状态 (Start Scan Idle)
* **拟物盘片按钮**：
  * 在页面中央放置一个直径 `160px` 的渐变绿圆形主按钮（`linear-gradient(135deg, #38705d, #2f604f)`），上带雷达发射图标 `📡` 与“开始搜索”文字。
  * 按钮底部带有一层温暖的微光投影（`box-shadow: 0 10px 25px rgba(128, 94, 69, 0.12)`）。
  * 盘片外圈加设两层双虚线装饰环轨（`border: 1.5px dashed rgba(47, 96, 79, 0.15)`），增添精致的智能硬件仪表盘交互感。
  * **微互动**：按钮配置 `:active` 缩放效果（`transform: scale(0.96)`），给予用户点击时的实体回弹反馈。

### 3.2 步骤一：扫描中状态 (Scanning Active)
* **雷达波动效**：
  * 按钮变为带有放大镜 `🔍` 的微缩圆形，并增加呼吸式放大动画（`scale(0.95)` 到 `scale(1.05)` 循环）。
  * 外圈释放渐变淡绿色脉冲环（`radar-pulse` 关键帧动画），多层脉冲向外扩散并自然淡化消失，营造生动且轻量的搜索感。
* **智能纯净列表**：
  * 只展示通过 `shouldIncludeBleDevice` 匹配成功的 `SX-` 设备以及广播了配网服务 UUID `1775244D-6B43-439B-877C-060F2D9BED07` 的设备。
  * **列表卡片化**：摒弃传统底边线列表，改为白底圆角卡片（`border-radius: 12px`），边缘带淡浅阴影。
  * **图形化信号强度**：将文字 `信号强度: -65 dBm` 改为图形指示，根据 RSSI 划分为三档展示：
    * `RSSI >= -60`：`📶 极佳` (森林绿)
    * `-75 <= RSSI < -60`：`📶 一般` (橙黄色)
    * `RSSI < -75`：`📶 较弱` (灰色)
  * **智能标签**：
    * 带有广播名 `SX-` 的设备加上标签：`我的初心`。
    * 无广播名但配网服务相符的设备加上标签：`测试机`，并自动呈现为 `初心设备 (无广播名 · MAC后位)`。

### 3.3 步骤二：Wi-Fi 信息配置表单与历史记忆
* **表单品质感提升**：
  * 输入框底色使用温暖的 `#fdfaf5`，边框使用细腻的 `rgba(128, 94, 69, 0.16)`。
  * “扫描附近”按钮改用圆角小胶囊，与表单齐平。
  * 密码眼睛图标采用精巧的锁形与眼睛符号（👁️/🔒），增加视觉焦点。
  * 操作按钮（重新搜索、发送配置）使用带有弧度的大圆角，颜色对比鲜明。
* **记忆用户历史 Wi-Fi (新增功能)**：
  * **读取**：在页面加载（`onMounted`）时，从小程序本地缓存读取历史记录：
    * `uni.getStorageSync("last_wifi_ssid")`
    * `uni.getStorageSync("last_wifi_password")`
    * 若存在，则自动回填至输入框。
  * **保存**：当用户点击“发送配置”开始配网时，自动将当前输入的 SSID 和密码持久化保存到缓存中：
    * `uni.setStorageSync("last_wifi_ssid", wifiSsid.value)`
    * `uni.setStorageSync("last_wifi_password", wifiPassword.value)`
* **核心逻辑不改动声明**：
  * **必须保持蓝牙底层的物理连接、会话握手（Security1）、特征值数据收发和状态机轮询流程 100% 完整与不改动**，确保前期的 Bug 修复不受任何干扰。

### 3.4 步骤三：连接状态与可折叠日志
* **日志折叠栏**：
  * 配网状态页顶部依然展示简洁、精美的等待联网面板（`spinner`）。
  * 原有巨大的暗黑控制台默认**隐藏**，改为底部一个低调的 `🛠️ 开发者调试日志` 点击栏。
  * 点击时平滑展开/折叠控制台，既保证普通用户界面的“白净温和”，又保留了硬件开发人员强诉求的实时日志追踪。

## 5. 验收标准

1. **未扫描阶段**：打开配网页面，应看到中心绿色大圆盘，点击时有轻微内缩效果。
2. **扫描中阶段**：列表不应夹杂普通耳机和其它周围设备。只能看见 `SX-` 设备或无名字的初心测试设备，信号显示为 `📶 极佳` 等图形字样，信号条颜色正常。
3. **Wi-Fi 填写页**：圆角卡片及输入框美观大方，颜色与初心品牌一致。
4. **日志跟踪页**：第三步默认不显示黑底控制台，点击“开发者调试日志 ▾”后能正常展开看日志，再次点击能收起。
