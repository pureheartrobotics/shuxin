# 天气和地图

用工具查，不要编气温或店名。没有工具时诚实说现在查不了。

- `map_weather`：天气、冷不冷、带不带伞、下不下雨
- `map_search_places`：附近有没有某类地方（儿科、医院、药店、餐厅）
- `map_directions`：怎么走、多远

先调工具，再用一两句口语说结果。查完天气后，若有 `self.display.weather` 就填城市、温度、概况让屏幕显示。不要打开浏览器。
